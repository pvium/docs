---
title: "Failed payouts"
description: "Investigate and resolve payout failures"
---

Open the batch detail page and check each payment’s status to identify which payments failed. Review any failure details before deciding whether to retry.

For API timeouts or duplicate-create errors, fetch the payout by its existing ID before creating another payout. See [Idempotency](/developers/idempotency) for recovery steps and [Track payout status](/dashboard/track-status) for batch and payment statuses.
